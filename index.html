        Syntax reference

        -L local forward 
        ssh user@ssh_server -L [bind_address:]listen_port:dest_ip:dest_port
        ssh alex@203.0.113.10 -L 2222:10.0.0.20:22

        Listens on your machine. The SSH server connects to dest_ip, so 127.0.0.1 there means the server.

        -R remote forward 
        ssh user@ssh_server -R [bind_address:]listen_port:dest_ip:dest_port
        ssh alex@203.0.113.10 -R 9000:127.0.0.1:5000

        Listens on the SSH server. Your machine connects to dest_ip, so 127.0.0.1 there means your machine.
